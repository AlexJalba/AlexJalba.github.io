Sergiu privacy policy

Last updated: 2 October 2026

Sergiu is a private assistant used only by Alex Jalba's family. It is not offered to the public.

What Sergiu accesses

  • Gmail (read only): to read and summarise email, for example school messages.
  • Google Calendar: to read events and, only after the account owner approves, add or change events.
  • Google Photos: to upload photos into albums Sergiu creates, and to read back only those photos.
  • Google Drive: to store backups in files Sergiu creates. It cannot see other Drive files.

How data is used and stored

Data is used only to provide the assistant to the family. It runs on a private server controlled by Alex Jalba. Data is not sold, shared with third parties, or used for advertising. Requests are processed by Anthropic's Claude API to generate replies.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Any family member can revoke Sergiu's access at any time at myaccount.google.com/permissions, and can ask Alex to delete their stored data.

Contact

Alex Jalba, via the support email shown on Google's sign-in screen.
